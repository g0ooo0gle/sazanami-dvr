# KonomiTV・Komorebi互換状況

この表は、Sazanami DVRで実際に使える操作と、まだ使えない操作を示します。確認対象はKonomiTV v0.14.1とKomorebi 1.1.0-beta6です。

「自動確認」は、合成データを使うテストが通っている状態です。「実環境確認」では、KonomiTVとMirakurunを使った一連の操作まで試しています。「Android上で確認」は、公式Komorebi APKをテレビ向け画面寸法のAndroid環境で動かした結果であり、Android TV実機の確認とは区別します。コマンドが応答するだけでは不十分です。

## 自動予約は層ごとに確認状況が異なる

| 対象 | 状態 | 確認したこと |
|---|---|---|
| KonomiTV v0.14.1のHTTP API | 実環境確認済み | 条件の一覧、追加、変更、削除 |
| KonomiTV v0.14.1の同梱画面 | 操作なし | HTTP APIはあるが、同梱画面から条件を編集する導線は確認できない |
| Komorebi 1.1.0-beta6 | ソース確認済み、実環境未確認 | 一覧、追加、削除を送信する。変更はクライアント内で送信前に失敗する |
| Sazanami DVRの保存 | 実環境確認済み | 条件の全項目をSQLiteへ保存し、再起動後に読み出す |
| Sazanami DVRの評価 | 実環境確認済み | 実番組表から通常予約を作り、再起動後の再評価で重複させない |
| 高度な番組条件の評価 | 自動確認済み | 番組検索と同じジャンル、除外、あいまい検索、映像、音声を自動予約でも評価 |
| 録画済み番組名の照合 | 実環境確認済み | 指定期間内の完全に同じ番組名を全チャンネルから照合し、新規・既存の自動予約を録画開始前に無効化。同じチャンネル内の照合は自動確認済み |
| 強制チューナー指定 | 自動確認済み | 条件の保存・読戻しのみ対応。録画への適用は非対応 |
| ワンセグ別出力 | 自動確認済み | 対応する指定は予約へ引き継ぐ。一意な部分受信サービスがない番組と未対応の指定は、条件を残したまま予約を作らない |

## KonomiTVでまだ使えない操作がある

| 操作 | CtrlCmd | 現在の扱い |
|---|---:|---|
| チューナー予約・動作一覧 | 1016、1066 | Sazanamiでは未対応。固定版KonomiTVとKomorebiで実際に到達する操作には含まれない。1033は自動予約条件の削除として対応 |

KonomiTVが送る単発予約の録画設定では、指定サービス録画の有効・無効、優先度、番組追従、前後余白、録画保存ルート内の相対フォルダー、対応済みのファイル名マクロ、字幕・データ放送、7種類の録画後動作、許可済みスクリプトに対応しています。チューナー指定など、表にない設定を含む単発予約は要求全体を失敗にし、一部だけ保存しません。

自動予約では、キーワードと除外語、正規表現、大文字と小文字の区別、番組名だけの検索、番組詳細、ジャンルと除外、あいまい検索、映像・音声、サービス、曜日と時刻、番組時間、有料・無料を評価します。録画済み番組名の照合では、指定期間内の完全に同じ番組名を同じチャンネルまたは全チャンネルから探し、一致する予約を無効状態で残します。対応形式の相対録画先、ファイル名、字幕・データ放送、7種類の録画後動作、許可済みスクリプトは作成予約へ引き継ぎます。

強制チューナー指定は条件として保存し、一覧と変更で同じ値を返します。ただし、Mirakurunの公開APIでは録画に適用できません。0以外の指定を含む条件からは予約を作らず、番組表の更新後に該当件数と固定理由だけを出力します。チューナーの自動選択を続ける場合は、強制指定を解除してください。

ワンセグ別出力は、KonomiTVの有効・無効と録画先を単発予約と自動予約で読み書きします。同じネットワークIDとTSIDを持つ別サービスのうち、部分受信、選択済み、検証済みの条件を満たすものが一件だけある場合に予約を作ります。候補がない場合や複数ある場合は別サービスを推測せず、単発予約は要求全体を失敗させます。自動予約は条件を残し、その番組の予約だけを作りません。

Sazanamiへ要求が届かないクライアント側の制限は、再現条件と代替手段を確認できた場合だけ「実現できない操作」として区別します。

## 対応済みの表示は実環境確認後に更新する

新しい操作は、通信形式の自動テスト、既存機能の回帰テスト、対象クライアントでの実環境確認がそろってから「対応済み」へ変更します。画面まで確認していない操作は、APIまたは実通信で確認した範囲を明記します。未確認のKonomiTV全体、Komorebi全体、EDCB全体への互換性は表明しません。

不具合を報告する場合は、家庭内のIPアドレス、ホスト名、番組情報、TS内容を除いた再現手順とSazanami DVRのバージョンを添えてください。脆弱性は公開Issueへ書かず、[セキュリティポリシー](../SECURITY.md)に従ってください。
