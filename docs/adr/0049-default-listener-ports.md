# ADR-0049: 既定ポートを4520～4522へまとめる

- Status: Accepted
- Date: 2026-08-11
- Deciders: Project owner
- Amends: ADR-0022のWebUIポート、ADR-0033の録画HTTPポート、ADR-0038のCtrlCmdポート
- Superseded by: None

## 背景

Sazanami DVR v0.0.29は、CtrlCmdに4510、録画HTTPに40773、WebUIに40772を使う。WebUIの40772はMirakurunの標準的な接続例と重なり、同じホストで使う場合は明示的な変更が必要になる。

プロジェクト責任者は、Sazanami専用として覚えやすい連番へ移し、既存の公開範囲と明示設定を維持する案を採用した。

## 判断

新しい既定値を次のとおり定める。

| 接続口 | 既定値 | 公開範囲 |
|---|---|---|
| CtrlCmd | `0.0.0.0:4520` | IPv4全interface |
| 録画HTTP | `127.0.0.1:4521` | loopback |
| WebUI | `127.0.0.1:4522` | loopback |

既存の`--listen`と`--http-listen`は残す。4510、40772、40773を含む許可済みポートは、利用者が明示すれば引き続き使用できる。旧ポートを拒否する互換処理や自動移行は追加しない。

CtrlCmdの既定LAN公開、録画HTTPとWebUIの既定loopback、アドレス検証、接続上限は変えない。DBと録画ファイルも変更しない。

## 理由

3つの接続口を4520からの連番にすると、Sazanamiの設定値を判別しやすい。固定値なのでKonomiTVとKomorebiの接続先も安定し、起動順で値が変わらない。

旧値の明示指定を残せば、既存の手動設定は移行期間中も利用できる。新しい設定形式や互換層を作らず、既定値と案内だけを小さく変更できる。

## 影響

- 既定値のまま更新する利用者は、KonomiTVとKomorebiの接続先を4520と4521へ変更する。
- 既存の起動引数でポートを明示している環境は、その値を継続して使える。
- WebUIのURLは`http://127.0.0.1:4522/`になる。
- ポート番号だけではLAN内外を制限しない。CtrlCmdの既定公開範囲と注意表示は維持する。

## 採用しなかった案

### 空きポートを自動選択する

クライアントへ固定の接続先を案内できなくなるため採用しない。

### 既存ポートを使用禁止にする

明示設定済みの環境を不必要に壊すため採用しない。

### 公開範囲も同時に変更する

ポート競合の解消とは別の判断である。CtrlCmdのLAN公開とHTTP／WebUIのloopback既定を維持する。
