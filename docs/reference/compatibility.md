# 対応範囲と互換性

Sazanami DVRは、KonomiTV v0.14.1が日常的に使う番組表、予約、録画、ライブ視聴のバックエンド操作を対象にしています。

EDCB全体、KonomiTVのほかのバージョン、Komorebiの全機能との互換性は保証していません。

## 対応している操作

- チャンネル、サービス、番組表の取得と番組検索
- 予約の一覧、追加、変更、取消し
- 録画中の状態確認と利用者による停止
- 自動予約条件の一覧、追加、変更、削除
- 局ロゴの取得
- ライブ視聴の開始、中継、終了
- 完成録画の一覧、詳細、再生
- HTTP Rangeによる録画再生

番組表はMirakurunまたはmirakcから取得してDBへ保存します。録画とライブのストリームは、必要なときだけ接続します。

## KonomiTV向けCtrlCmd

KonomiTV v0.14.1固定プロファイルで受け付けるコマンド番号は19個です。

```text
2200, 1060, 1021, 1029, 2060, 1025,
2011, 2013, 2015, 1014, 1087, 1081,
2131, 2132, 2134, 1033, 1073, 301, 1074
```

| 用途 | 番号 |
|---|---|
| 起動確認 | `2200` |
| チャンネル・サービス | `1060`、`1021` |
| 番組表・検索 | `1029`、`1025` |
| 予約・録画中確認 | `2011`、`2013`、`2015`、`1014`、`1087`、`1081` |
| 自動予約 | `2131`、`2132`、`2134`、`1033` |
| 設定・ロゴ | `2060` |
| ライブ視聴 | `1073`、`301`、`1074` |

この19個は固定プロファイルの自動テストで確認しています。番号を受け付けることだけで、KonomiTVのすべての画面操作を保証するものではありません。

## 録画と再生

放送中の番組へ新しく予約を追加した場合は、作成から5分以内で、録画余白を反映した終了予定まで60秒以上残っていれば現在時刻から録画を始めます。過ぎた部分は保存できません。

録画中の停止要求では、188バイト以上を保存し、ファイルとDBの確定処理に成功した場合に部分録画として公開します。正常終了した録画とは別の状態で記録します。

共通の録画・再生HTTPでは、録画一覧、録画詳細、TS取得、Range取得、ロゴを提供します。Komorebi 1.1.0-beta6向けには、resolver、xcode、ライブ用HTTP/HLSも用意しています。いずれも映像の解像度、ビットレート、コーデックは変換しません。

## Komorebi向けの追加範囲

Komorebi 1.1.0-beta6向けには、KonomiTV向け19個に加えて次の2個を受け付けます。

| 用途 | 番号 |
|---|---|
| 完成録画の一覧 | `2017` |
| 完成録画の詳細 | `2024` |

重複を除いた対応コマンドは合計21個です。接続方法は[Komorebiとの接続](clients/komorebi.md)を参照してください。

## 対象外・未保証

- EDCBの全機能
- チューナー操作系の`1016`、`1066`
- KonomiTV v0.14.1以外の動作
- Komorebiの全画面・全機能
- 録画映像のトランスコード
- 実サムネイル、実チャプター、実タイル画像
- すべての放送波、検索条件、実機構成

自動テスト、実環境、クライアント画面の確認結果は別々に扱います。実装上の確認範囲は開発者向けの[テスト](../development/testing.md)にまとめています。
