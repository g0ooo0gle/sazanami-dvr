# KomorebiからSazanami DVRへ接続する

この手順は、Komorebi `1.1.0-beta6`からSazanami DVRへ直接接続する場合に使います。
確認済みなのは公式APKをテレビ向け1080p画面のAndroid環境で動かした結果です。
Android TV実機またはAndroid TV専用システムイメージでは、まだ確認していません。

Android上で確認済みのライブ視聴は、Komorebiの直接配信です。非直接ライブでは、プレイリストと短い分割TSを
使うHLSで元の映像を配信します。こちらは自動テスト済みですが、公式APKと実放送ではまだ試していません。

## 先にSazanami DVRを起動する

Komorebiを別の端末で使う場合、Sazanami DVRのCtrlCmdはLANから接続できる必要があります。
`recording serve`は既定で`0.0.0.0:4520`に待ち受けるため、通常は追加設定が不要です。
認証はないので、信頼できる宅内LANだけで使い、インターネットへ直接公開しないでください。

録画済みTS、局ロゴ、非直接ライブのHLSを使う場合は、HTTPもLANで待ち受けます。

```text
sazanami-dvr recording serve \
  <ほかの引数> \
  --http-listen 0.0.0.0:4521
```

## Komorebiの接続先を設定する

Komorebiの設定画面で、次の順に設定します。

1. 「接続設定」を開く
2. 「利用するシステム」で`EDCB (EpgTimerSrv)`を選ぶ
3. 「EDCB (IPアドレス)」にSazanami DVRを動かすPCのLANアドレスを入力する
4. 「EDCB (TCPポート)」に`4520`を入力する
5. 録画済みTS、局ロゴ、非直接ライブも使う場合は、「EDCB (HTTP/HTTPSポート)」に`4521`を入力する
6. Android上で確認済みの経路を使う場合は、「優先ソース」で`EDCB (ダイレクトストリーミング)`を選ぶ

録画再生方法では、直接再生に加えて「HTTP API」も選べます。HTTP APIを使う場合、画質は
「オリジナル（変換なし）」を選んでください。Sazanami DVRは録画済みTSの内容を変えずに返します。
解像度やビットレートは変換しません。

「メインシステムに従う（トランスコード）」を選ぶと、KomorebiはEDCB WebUI互換のHTTPへ接続します。
Sazanami DVRはこの経路で、元のTSを1〜2秒の分割TSに分け、HLSとして返します。映像自体は変換しないため、端末が
元の映像形式を再生できる必要があります。

## 画面から確認する

次の順に一件ずつ確認します。

1. 番組表を更新し、複数の放送局と番組が表示される
2. 将来の番組を予約し、予約一覧で有効・無効を変更してから取り消せる
3. 現在放送中の番組を開き、「視聴する」で主画面のライブ視聴が始まる
4. 視聴画面を閉じた後、別の番組を視聴できる

二画面で見る場合は、主画面の視聴を始めてから次のように操作します。

1. 上キーで再生メニューを開く
2. 「二画面」の「開始」を選ぶ
3. 番組情報の表示が消えた後に下キーで放送局一覧を開く
4. 右画面で見る別の放送局を選ぶ
5. 戻るキーで右画面を閉じ、もう一度戻るキーを押して主画面も閉じる

右画面を閉じた直後に、Komorebiの再生エンジンが入力終了をエラーとして記録する場合があります。
確認環境では主画面の視聴を続けられ、10秒以内に右画面の接続が解放されました。

非直接ライブを試す場合は、「優先ソース」を「メインシステムに従う（トランスコード）」へ戻し、画質に
「オリジナル（変換なし）」を選びます。主画面と二画面、プレイリスト、分割TS、途中からの再取得までは
自動テスト済みです。実際に使うなら、現時点では直接配信が確実です。

録画済み一覧、詳細、元のTSの直接再生と30秒送りは、KomorebiのAndroid画面でも確認済みです。
録画再生方法をHTTP APIへ切り替える経路は自動テスト済みですが、Android画面ではまだ確認していません。
二画面の左右入替と画面サイズ変更、映像変換、キャストには未対応または未確認の項目があります。
非直接ライブのHLSもAndroid画面では未確認です。
現在の範囲は[互換実装表](compatibility.md)を参照してください。

## うまくいかない場合

| 状況 | 確認すること |
|---|---|
| 番組表を取得できない | Sazanami DVRが先に起動しているか、LANからCtrlCmdへ接続できるか |
| 予約を保存できない | 予約開始前の番組か、Sazanami DVRが最新のDBを開いているか |
| ライブ視聴で動画変換のエラーが出る | 確認済みの直接配信へ切り替えるか、非直接ライブの画質を「オリジナル（変換なし）」にしているか |
| ライブ視聴を開始できない | 番組表の放送局とMirakurunの放送局が一致するか、Mirakurunがストリームを返せるか |
| 録画済みTSや局ロゴを取得できない | `--http-listen`をLANへ明示し、KomorebiのHTTPポートが一致するか |
| HTTP APIで録画を再生できない | 録画が完成しているか、画質に「オリジナル（変換なし）」を選んでいるか |

問題を報告するときは、家庭内のIPアドレス、ホスト名、利用者名、番組情報、TS内容を含めないでください。
